# AI 生成画像の運用ルール（なべっこ）

採用日: 2026-10-31（Asia/Tokyo）。  
更新: 2026-11-14。無料素材の参照利用を任意で可にした。  
対象: 週刊号のピックアップ等で使う、トピック文から起こす AI 生成ビジュアル。  
関連: [pipeline.md](./pipeline.md)、[`scripts/draft-prompt.md`](../scripts/draft-prompt.md)、[POLICY.md](../POLICY.md)。

本ファイルは運用契約です。法的助言ではありません。公開前の最終判断は人間（運営）にあります。

---

## 採用の前提

- **広報誌 PDF から抽出した画像は記事に埋め込まない**（`data/kouhou/extracted/.../images/` は題材判断の参考のみ。`public/images/kouhou/` へのコピー・Markdown 埋め込みは禁止）
- 口コミの Threads 埋め込み方針は変更しない（再アップロード禁止・埋め込み優先）
- ピックアップの視覚は、**トピック文を主入力**にした AI 生成画像で補う（権利確認済みの自前写真等が将来増えても、広報 PDF 切り出しは使わない）

---

## ロックしたルール（5 項）

| # | ルール | 実務 |
| :---: | :--- | :--- |
| 1 | **主入力はトピック文。広報画像は参照禁止** | 生成プロンプトの主はトピック文。広報 PDF 画像・抽出 JPEG・スキャンは参照にも「似せて」にも使わない。**任意:** 商用・編集利用が許された無料素材（Unsplash / Pexels / Pixabay 等）を **構図・光・色の参照だけ**に使ってよい。素材そのものは記事に埋め込まない。参照は固有施設の複製や顔の写実に寄せない |
| 2 | **実在の識別可能な人物の写実を避ける** | 顔が判別できる写実ポートレート、特定個人に寄せた顔、子どもの顔の写実は出さない。人が出る場合は後ろ姿・シルエット・ぼかし・イラスト化。施設・風景・物・雰囲気を優先 |
| 3 | **モデル／サービスの利用規約に従う** | 商用・編集利用が許されるツール／プランだけ使う。禁止用途・第三者商標の乱用・なりすましをしない。API キーはリポジトリに書かない。無料素材を参照にする場合も、その素材のライセンス（商用・改変）を確認する |
| 4 | **生成である旨を画像内で短く開示** | 本文に長い注記は書かない。画像の四隅（右下または左下）に短い透かし（既定: `AI生成`）を焼き込む。alt にも「AI生成」を含めてよい。無料素材参照から生成した場合も開示は `AI生成`（素材クレジットを本文に長く書かない） |
| 5 | **公開前に人間が確認する** | 新規号は Frontmatter **`draft: true`**。ファクト・固有名詞・画像の違和感を確認してから `draft` を外す |

---

## プロンプトの型（最低限）

毎回の生成指示に次を含める。

- 主題（トピックを一般化した風景・物・施設の外観）
- 季節・光（号の時期に合う柔らかい自然光。ネオンや過剰な演出は避ける）
- 人が出るなら後ろ姿・シルエットまで
- 読める看板・ロゴ・長い文字を出さない
- 実在の特定施設・通り・象徴物のコピーに寄せない
- 参照画像があるときは「光・色・構図だけ。被写体や人物・ロゴはコピーしない」

号内の寄せ（写真寄り／イラスト寄り）は揃える。  
画風や素材選定の細かい好みは本ファイルの範囲外とする。

## 置き場所と命名

| 項目 | 値 |
| :--- | :--- |
| ディレクトリ | `public/images/generated/vol-N/` |
| ファイル名 | 短く内容が分かる英数字ケバブ（例: `mitane-kohoku-stage.png`） |
| Markdown | `![短い説明（AI生成）](/images/generated/vol-N/….jpg)` |
| 開示 | **画像内透かし**（右下／左下）。文言は短く（例: `AI生成`）。本文の長い注記は置かない |
| 参照用素材（任意） | 記事・`public/` に置かない。下書き用の一時置き場のみ。生成後も埋め込まない |

広報抽出用の `public/images/kouhou/` とは別系統です。混在させないでください。

## Step C での位置づけ

1. 広報・口コミの**テキスト**から題材を選ぶ（抽出画像は見ても埋めない）
2. ピックアップごとに、トピック文から生成プロンプトを書く（上記 1〜3）。必要なら無料素材を1枚だけ参照用に選ぶ
3. 利用可能な生成手段で画像を作り、`public/images/generated/vol-N/` に置く  
   - 当面の例: Cursor の画像生成（参照パスを渡せる場合はそれも可）など、手元で使える手段  
   - 外部画像 API のキーが無い場合は無理に追加しない（秘密を捏造しない）
4. 画像に短い透かし（`AI生成`）を入れてから記事へ埋め込む。号は **`draft: true`** のまま人間レビューへ

チェックリスト表示: `npm run draft -- --vol N --date YYYY-MM-DD`（正本は `scripts/draft-prompt.md`）。

---

## やらないこと

- 広報 PDF／抽出画像を生成の入力・参照・「似せる」指示に使うこと
- 無料素材を **そのまま**記事に貼ること（参照専用。出すのは生成結果だけ）
- 実在人物の写実ポートレートや、子ども・顔が判別できる写実を記事ヒーローにすること
- 生成画像を「広報写真」「取材写真」と誤認させるキャプション
- 本文に長い生成注記を重ねること（開示は画像内の短い透かしが正）
- `draft: true` のまま本番公開扱いすること（フラグ解除は人間の明示操作）
